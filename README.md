# Omnica
Harmonized Multi Agent Selfcare App

Millions of patients in developing nations are struggling with need for self health care amid problems like increased pollution, environmental hazards, life stye changes etc.
Omnica is an AI system that utilizes a combination of Patient Diagnostic Records,  Prescriptions, Video consultations etc. and fusing with Open AI technologies to provide doctors and patients with a comprehensive one-click analysis, treatment recommendations and self-care instructions for better health

As we understand in the healthcare system, there might be multiple vendors having multiple sophisticated offerings which need to be provided as an interconnected system. And that's the reason we have developed Omnica using a multi-agent framework.We have used Azure AI Agent Service for insurance services, Autogen agents to identify any toxicity or sensitivity in data, Semantic Kernel for data extraction and processing. We have also even integrated with third party agents like Saleforce Agentforce to show how multiple agents can work together.
